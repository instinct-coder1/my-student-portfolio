# Muhammad Razin Shaikh — Student Portfolio

A responsive personal portfolio website built for the BossCoder School of Technology Web Development Project.

## Built with
- HTML5 for semantic page structure
- CSS3 for layout, responsive design, theme variables and visual styling
- Vanilla JavaScript for theme switching, mobile navigation, active-section navigation and contact-form validation

## Features
1. Home section with student introduction and profile avatar
2. About Me section
3. Education timeline
4. Technical and non-technical learning areas
5. Project cards with GitHub links
6. Hobbies and interests
7. Achievements and milestones
8. Contact form with client-side validation
9. Dark and light theme toggle
10. Smooth scrolling and active navigation state
11. Responsive layout for desktop, tablet and mobile

## Run locally
1. Clone or download this repository.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

No framework, package installation or build step is required.

## Personalise before submission
- Add your school name, board and passing year in Education.
- Add your actual hobbies and interests.
- Add verified certificates, workshops or achievements when available.
- Add your preferred public email address and LinkedIn profile URL.
- Review project descriptions and technology tags to ensure they match each repository.
- Replace the initials avatar with a suitable profile photograph if desired.

## Contact form note
The form validates name, email and message fields in the browser and displays a confirmation. It does **not** send or store messages because no backend or email service is connected. This matches the assignment brief's note about a front-end-only form.
