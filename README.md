# Mahammad Rajin Shaikh — Student Portfolio

A responsive student portfolio for presenting my education, learning areas, projects and progress. Built with semantic HTML, modern CSS and vanilla JavaScript.

## Design and technology
- HTML5 for semantic page structure and accessible content
- CSS3 for responsive layouts, glassmorphism surfaces, gradients and theme variables
- Vanilla JavaScript for navigation, theme switching, project filters, scroll progress and contact interaction
- Google Fonts: DM Sans and Space Grotesk

## Features
1. Glass-style sticky navigation with active section tracking
2. Responsive hero section and profile card
3. About and education timeline
4. Skills cards with honest beginner/learning labels
5. Project cards linked to GitHub repositories
6. Project filters: All, Web Development, AI/ML and Learning
7. Interests and milestone sections
8. Dark and light theme toggle (preference saved in the browser)
9. Reading progress indicator and back-to-top control
10. Responsive mobile navigation
11. Accessible focus states and reduced-motion support
12. Contact form validation that prepares an email to bstmzk@proton.me

## Run locally
1. Clone or download this repository.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.

No framework, package installation or build step is required.
